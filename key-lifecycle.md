# Ciclo del único API key temporal

Nombre previsto: `write-report-benchmark-temp-2026-08-18`.

- Se crea únicamente después de una confirmación específica del usuario.
- Se transmite al proceso de ejecución solo en memoria; no se guarda en `.env`, archivos, argumentos, logs, Git o el ZIP.
- No se usa, modifica ni revoca el key original `chatgpt-gratis-original-experiments-2026-08`.
- Tras publicar y comprobar la evidencia y el artículo, se solicita una confirmación nueva para revocar únicamente el key temporal nombrado arriba.
- Revocar el key no autoriza borrar el proyecto, otros keys, datos, evidencia o releases.
